LOUD LEDGER PEER PROTOTYPE
==========================

1. Right-click the ZIP and choose Extract All.
2. Open the extracted Loud-Ledger-Peer-Prototype folder.
3. Double-click START-HERE.html.
4. Use a current version of Edge, Chrome, or Firefox.

Do not open START-HERE.html from inside the ZIP preview. If Windows shows an
Unblock checkbox under the ZIP file's Properties, select it before extracting.

The persistent TEST MODE banner confirms that the peer build loaded. In this
build, one six-hour checkpoint takes six seconds so the gameplay loop can be
tested in one session. Use Reset economy v2 in the lower-left to restart.

STATUS AND SAFETY
-----------------

This is a local entertainment simulation. It is not connected to Robinhood
Chain, a brokerage account, a wallet, or real funds. Nothing is redeemable and
there are no promised returns. Experimental Solidity source and tests are
included under SOURCE for technical review; no contracts are deployed by this
package.

Suggested route: Practice -> Land -> Plant -> Harvest -> Daily Demand -> Work.
The Farm is a 36-slot capacity preview; the starter profile has three Access
credentials. Crew progress is accelerated in Test Mode so its cosmetic goal can
be demonstrated during a short review.
